# WinToolKit CMD Launcher

### A simple one-click launcher for WinToolKit

WinToolKit CMD Launcher is a small Windows command file that downloads the latest published WinToolKit release from GitHub and starts it with administrator privileges.

The launcher is designed to make getting started simple: download `WinToolKit.cmd`, run it, and let it retrieve the latest published version for you.

## 📥 Download

**[Download the latest WinToolKit CMD Launcher](../../releases/latest)**

1. Download `WinToolKit.cmd` from the latest launcher release.
2. Save it somewhere convenient on your Windows PC.
3. Double-click `WinToolKit.cmd`.
4. Approve the Windows administrator prompt when asked.
5. The launcher downloads the latest published WinToolKit release and starts it.

## ✨ What it does

- **One-click launch** — Start WinToolKit from a single CMD file.
- **Latest published release** — Retrieves the latest published WinToolKit release from GitHub.
- **Administrator permissions** — Requests elevation when required.
- **Simple setup** — No need to manually download the PowerShell script first.

## ⚙️ Requirements

- Windows 10 or Windows 11
- <b>Internet connection</b>
- Permission to run PowerShell scripts
- Administrator approval for elevated operations

## ⚠️ Important information

- The launcher downloads and runs a PowerShell script from the WinToolKit GitHub project.
- Only run the launcher if you trust the project and its source.
- Windows may show a security or administrator prompt. Review it before approving.
- The launcher needs internet access to download WinToolKit.
- If the download fails, check your internet connection and confirm that a published release is available.
- The launcher and the WinToolKit application are separate components. This repository contains the launcher, not the full toolkit source.
